# AgroVision 2 — карточка товара за три минуты

FastAPI + локальные модели + Canvas-редактор без сборки frontend и без платных API.
Загрузка → оформление во время обработки → проверка фактов → 1–4 карточки → редактор → PNG/ZIP.

## Запуск в PyCharm / терминале

Рекомендуется Python 3.11 или 3.12. Распакуйте проект **в отдельную папку**, откройте её в PyCharm и выберите виртуальное окружение.

```bash
python -m venv .venv
```

Активируйте окружение:

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
source .venv/bin/activate
```

Для полной функциональности:

```bash
python -m pip install -r requirements-full.txt
python -m uvicorn backend_main:app --reload
```

Откройте `http://127.0.0.1:8000` в обычном браузере. Команду запуска выполняйте из папки с `backend_main.py`.
В PyCharm можно использовать терминал проекта и его выбранный интерпретатор.

Для CPU на Windows/Linux можно **перед** полной установкой установить CPU-версии PyTorch:

```bash
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements-full.txt
```

Для проверки интерфейса без тяжёлых моделей достаточно:

```bash
python -m pip install -r requirements.txt
python -m uvicorn backend_main:app --reload
```

В этом случае снимите «Удалить фон у товара», раскройте «Локальное распознавание» и отключите OCR и CLIP. Сведения вводятся вручную. Если оставить функции включёнными без установленных моделей, программа покажет предупреждения и позволит продолжить с оригиналами.

### Первая загрузка моделей

- BiRefNet (`rembg`) удаляет фон.
- EasyOCR читает русский и английский текст на **оригиналах** товара и дополнительных фотографий.
- `openai/clip-vit-base-patch32` предлагает категории локально.

При первом обращении библиотеки скачивают веса из своих официальных источников (GitHub, Hugging Face и их хранилища). Нужны Интернет и свободное место для PyTorch и моделей; загрузка и первый запуск могут занять несколько минут. После кеширования обработка работает локально. Ключи API не нужны. Указанная цель «три минуты» не является измеренной гарантией: время зависит от CPU/GPU, размера и количества фотографий и прогрева моделей. Сейчас EasyOCR настроен на CPU, CLIP сам выбирает доступный CUDA, rembg использует CPU-пакет.

Если модель не загрузилась, смотрите предупреждение интерфейса и traceback в терминале. После исправления установки или доступа нажмите «Повторить обработку». Проверка TLS и контрольных сумм моделей не отключается.

## Что реализовано

- Основное фото и до пяти дополнительных JPG/PNG/WEBP, до 12 МБ и 24 Мп каждое. Можно сохранить фон и у JPG.
- Отдельная обработка в очереди: оформление доступно параллельно. Прогресс по завершённым этапам, а не выдуманный процент внутри модели.
- Studio / Organic / Promo; цвет или изображение фона; 1:1, 16:9, 9:16; локальные шрифты с кириллицей; подставки и формы плашек.
- Семь шаблонов: главная, характеристики, габариты, крупные планы, выноски, комплектация, описание. Выбор от одного до четырёх создаёт отдельные карточки одного товара.
- Категории по изображению и OCR, отображение уверенности OCR, ручной ввод и подтверждение. Проценты CLIP — относительное сходство среди категорий, не вероятность правильного ответа.
- Автокомпозиция включает только подтверждённые характеристики. Отсутствующие размеры/подписи остаются явными заполнителями, которые редактор отмечает предупреждением. Они не являются распознанными фактами.
- Редактор: перемещение мышью, координаты и размеры, поворот, порядок слоёв, видимость, блокировка, удаление, дублирование, отмена/повтор. Каждый текстовый объект редактируется. Подставки, органические формы и плашки — тоже отдельные объекты.
- Крупные планы: `cover`, масштаб и смещения фотографии внутри рамки. Изменение фото, яркость, контраст и насыщенность.
- Автоподбор размера текста при генерации, ручное «Вписать текст в блок», предупреждения о переполнении и выходе текста за холст.
- PNG текущей карточки или ZIP всех карточек, длинная сторона 1200/2000/3000 px. Один Canvas-рендерер для редактора и экспорта; рамка выделения в PNG не попадает.
- Сохранение на сервере, повторное открытие последнего проекта и экспорт/открытие JSON.
- Оценка заполненности, демонстрационные требования по категории, предупреждения о качестве фото и категоричных заявлениях. Цена не считается обязательной.

## Редактор

Выберите слой на холсте или в левом списке. Сверху списка — передний план. Кнопки «↓ Слой / ↑ Слой» находятся в свойствах справа.

- Перетаскивание — перемещение объекта.
- Двойной щелчок по тексту — фокус на его редактировании справа.
- Стрелки — сдвиг на 1 px, Shift + стрелки — на 10 px.
- Delete / Backspace — удалить выбранный разблокированный объект.
- Ctrl/Cmd + Z — отмена, Ctrl/Cmd + Shift + Z — повтор.
- У крупного плана меняйте «Масштаб внутри рамки», «Сдвиг фото X/Y»; рамка остаётся на месте.

Тексты и плашки — отдельные слои. Чтобы двигать их вместе, измените оба слоя; группировка в этой версии не реализована. Масштабирование выполняется через размеры в свойствах, без угловых ручек.

Возврат в сведения не уничтожает сцены. «Собрать карточки» повторно заменяет ручные изменения только после подтверждения. Для сохранения текущих сцен возвращайтесь через «Открыть последний проект» либо сохраняйте до пересборки.

## Проекты и сохранность данных

`results/<uuid>.json` — проект версии 2; `uploads/<uuid>/` — оригиналы, вырезанные изображения и фоны. Сохраняйте **обе папки** при переносе.

«Проект JSON» — резервная копия композиции и сведений со ссылками на локальные изображения. **Фотографии внутрь JSON не встроены.** «Открыть JSON» восстанавливает его на том же сервере, где сохранён соответствующий проект и изображения. При переносе на другой компьютер сначала перенесите `results` и `uploads`.

JSON-черновики прежней версии автоматически не мигрируются. Исходные файлы старой версии не требуется удалять.

Кнопка «Сохранить» сохраняет все карточки; автоматического сохранения каждого движения нет. Вкладка предупреждает о несохранённых изменениях сцены. Последний UUID хранится в localStorage браузера.

Очередь обработки однопоточная и находится в процессе Uvicorn. Используйте один worker. При `--reload` / перезапуске текущая обработка помечается прерванной; можно повторить её или перейти к ручному заполнению. Фотографии и сохранённые композиции остаются на диске.

Это локальная конкурсная версия без учётных записей, разграничения доступа и серверной очереди Redis. Для публичного многопользовательского размещения нужны отдельная авторизация и изоляция проектов. Предварительная модерация — проверка по простым правилам, а не официальное одобрение маркетплейса.

## API / интеграция

Интерактивный контракт OpenAPI: `/docs`; JSON-схема: `/openapi.json`.

| Метод | URL | Назначение |
|---|---|---|
| GET | `/api/health` | Готовность HTTP-сервера (не наличие моделей) |
| POST | `/api/projects` | Multipart: `product_image`, повторяемое `details`, булевы параметры удаления фона, `use_ocr`, `use_vision`. Возвращает 202 и проект с UUID |
| GET | `/api/projects/{id}` | Проект, состояние обработки, результаты OCR/категории, оценка готовности |
| POST | `/api/projects/{id}/retry` | Повторная обработка оригиналов, 202; 409 если уже выполняется |
| PUT | `/api/projects/{id}` | Сохранить `{product, settings, scenes}`; 409 во время обработки |
| POST | `/api/projects/{id}/background` | Multipart `image`, возвращает локальный URL фона |

`product.facts`: `{label, value, source: "user" | "ocr", confirmed: boolean}`. `product.confirmed` — ручное подтверждение всего набора сведений.

`job.status`: `queued`, `running`, `done`, `failed`, `interrupted`. При `done` могут остаться предупреждения о недоступных моделях; это не означает успешное распознавание. `job.completed/total` считает законченные попытки этапов.

`scenes[]`: `{id, template, title, width, height, background, nodes}`. Массив `nodes` расположен от заднего плана к переднему. Типы: `text`, `image`, `shape`, `line`, `pedestal`. Координаты в пикселях сцены. Для каждого объекта сохраняются `id`, `title`, `x/y/w/h`, `rotation`, `opacity`, `visible`, `locked` и свойства своего типа. Общий рендерер — `frontend/scene.js`.

PNG и ZIP генерируются в браузере, отдельный серверный endpoint экспорта не нужен.

## Проверки

```bash
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
```

8 API-тестов: реальная запись и чтение проектов, очередь, валидация изображений, обязательность подтверждений, повтор обработки; вызовы тяжёлых моделей заменены контролируемыми адаптерами. Проверяется, что OCR получает RGB-массив оригинала, а не неподдерживаемый объект PIL. Эти тесты **не измеряют качество моделей**.

Браузерные проверки (при запущенном сервере):

```bash
python -m playwright install chromium
python tests/browser_smoke.py
python tests/browser_templates.py
```

Можно задать `CHROMIUM_PATH` для установленного Chromium и `APP_URL` для другого адреса сервера. Smoke-тест создаёт тестовый проект без моделей, проверяет полный путь, PNG, ZIP и повторное открытие. Второй тест проверяет 63 сочетания стиля/формата/содержимого, отсутствие неподтверждённых свойств в автокомпозициях и мобильную страницу загрузки. Тестовые артефакты пишутся в системную временную папку.

В среде разработки эти проверки прошли. Реальные веса BiRefNet/EasyOCR/CLIP здесь не загружались; качество распознавания, скорость полного нейросетевого сценария и работа на вашей ОС требуют проверки на ваших фото.

Локальные DejaVu-шрифты и лицензия находятся в `frontend/fonts/`; платные ресурсы и CDN для работы интерфейса не используются.
